## 👋 About This Repository

This repository contains the tasks I completed as part of the **Datheon Python Programming Internship (4 Weeks)**. Each task focuses on a core Python skill and is built as a clean, modular, runnable program using only the Python standard library.

## 📂 Projects

| # | Project | Description | Skills |
|---|---------|-------------|--------|
| 1 | [🎮 Hangman Word Guessing Game](./task1_hangman) | Console Hangman with ASCII gallows art, 6 attempts, and duplicate-guess protection | Strings, loops, sets, functions |
| 2 | [📈 Stock Portfolio Tracker](./task2_portfolio) | Calculates portfolio value and % gain/loss per holding, then exports a CSV summary | Dictionaries, CSV, file I/O, formatting |

> More tasks will be added here as I complete them. ⭐

## 🚀 Getting Started

**Requirements:** Python 3.8 or higher. No external packages needed.

```bash
# 1. Clone the repository
git clone https://github.com/m145jawad-wq/datheon-python-internship.git
cd datheon-python-internship

# 2. Run any project
python task1_hangman/hangman.py
python task2_portfolio/portfolio.py
```
